Manual Setup & Removal

To remove the global Forward-Auth config, go to Zoraxy → Settings → Auth Provider → clear the Forward Auth address field and save.

To set up manually in Zoraxy:

  1. Forward-Auth: Settings → Auth Provider → Forward Auth → Address: http://127.0.0.1:9698/check, enable X-Original Headers, Ignored Paths: /.within.website/
  2. Per Route: HTTP Proxy → rule → Authentication → Forward Auth
  3. Vdir per Route: HTTP Proxy → rule → Virtual Dirs → Add: /.within.website/ → 127.0.0.1:9698
  4. Disable Route: HTTP Proxy → rule → Authentication → None, then delete the /.within.website/ vdir
